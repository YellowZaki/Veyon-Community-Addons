# Veyon Community Addons

Suite de addons libres y de código abierto para **Veyon (versión 4.11.4)** sobre Windows.

## 📦 Proyectos Disponibles

| Addon | Estado | Descripción |
| :--- | :--- | :--- |
| **[Internet Access Control](./internet-access-control)** | 🟢 Completado | Bloqueo y control de acceso a Internet en tiempo real mediante Windows Firewall, preservando la red local y los puertos de Veyon. |
| **[Screen Recorder](./screen-recorder)** | 🟢 Completado | Grabación simultánea de pantallas de alumnos o profesor en archivos de video (MP4 H.264 / AVI MJPEG) con panel de control en tiempo real. |
